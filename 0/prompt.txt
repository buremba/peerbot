2. Key Technical Concepts:
   - **Lobu Behaviors** (internal DB vocabulary: `watchers`) — scheduled agent runs with cron + window granularity
   - **Canvas windows** — `canvas_windows` table keys the behavior as `watcher_id`; holds `run_id`, `model_used`, `extracted_data`, `content_analyzed`
   - **`complete_window` / `client.behaviors.completeWindow({window_token, extracted_data, behavior_run_id})`** — the only path by which a window Behavior's output is persisted
   - **`replace_existing: true`** — required for any Behavior whose cron is more frequent than its window granularity, else every run after the first is silently discarded
   - **Extraction schema derivation** — `deriveWatcherExtractionSchema()` resolves `keying_config.entity_type` → entity type's `metadata_schema`, wrapped as an array at `entity_path`; fallback is `watchers.reaction_input_schema`; returns null otherwise
   - **`event_kinds` registry** — declared ON an entity type (including the org-wide `$member` type), keyed by `semantic_type` slug, each with optional `metadataSchema` (JSON Schema) and `jsonTemplate` (render template)
   - **`$member` entity type** — org-wide event-kind registry (`ensureMemberEntityType`); this org has 11 registered kinds: fact, note, todo, event, content, summary, decision, guidance, identity, preference, observation
   - **`knowledge.save`** — SDK write that persists a knowledge event with `semantic_type`; `entity_ids` optional
   - **`notifications.send`** — documented as "the way a Behavior reaction surfaces its digest to a chat channel"; writes an `agent_message` in-app notification and fans out to active Slack/Telegram bot connections
   - **Events are append-only and superseded events are filtered out of the read path** — `supersedes_event_id` chains; you cannot count historical writes from a plain `SELECT`
   - **Ajv validation** in complete-window.ts with `removeAdditional: true, strict: false`
   - **Dispatch modes**: window behaviors (must call complete_window) vs event turns (must NOT call complete_window; final text IS the output)
