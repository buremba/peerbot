2. **Key Technical Concepts:**
   - Lobu monorepo, Bun workspace, worktree-per-task via `make task-setup NAME=<slug>`
   - Gate sequence: `make review-fix` → stage by explicit path → `make pre-pr-remote` (Depot, 18 lanes, tree attestation) → commit → `gh pr create` → `make review` (posts required `pi-review`) → `make ui-review` → `gh pr merge --squash --admin`
   - **Depot failure classification (4 buckets), co-developed with peers:** (1) named infra — download/provisioning failures before test code runs, retry is correct; (2) named marginal — `5000.xx ms` gateway-Postgres hook timeouts, retry-green is a real warning; (3) fixture/state error wearing a timeout costume — a test body that throws reports as a 5s timeout; (4) unknown cause — unattested.
   - `depot ci logs <run_id>` serves only the LAST attempt; to read a failed attempt, get `attempt_id` from `depot ci status <run> --output json | jq '.workflows[0].jobs[].attempts[]'` and pass it positionally **without** `--job`.
   - `check-drift` reads the **branch's own** submodule pin, not the merge ref — merging the parent bump doesn't fix branches.
   - `gh pr checks` shows the last **completed** run per check, not the run for the current head — compare `headSha` before acting on red.
   - `pi-review` and `ui-review` are **commit-bound**; a rebase silently drops them and the PR sits BLOCKED on a check that never arrives.
   - `make pre-pr-remote` attests the **staged** tree; a clean post-rebase worktree is refused. Use `git reset --soft origin/main` then `git commit -C <sha>` after passing.
   - bun 1.3.5 ignores `timeout` in bunfig; CLI `--timeout` is required (#2691, `4873ecf9`).
   - `GATEWAY_TEST_TIMEOUT_MS = 30_000` in `scripts/run-gateway-test-lanes.mjs` — numeric separator means `git grep "timeout 30000"` false-negatives; use `git merge-base --is-ancestor 4873ecf9c416af64ada6eea6842fbafa31acf311 HEAD`.
   - Capability model: `packages/core/src/capabilities.ts` — `BROWSER_CAPABILITIES` (`browser.tabs`, `browser.scripting`, …), `OS_CAPABILITIES` (`os.files`), `PLATFORM_ALLOWLIST` maps `macos` → OS+BROWSER+MAC, `chrome-extension` → BROWSER.
   - `required_capability` forces device pinning at connection create/update (`packages/server/src/tools/admin/manage_connections/handlers/device-binding.ts:70-111`, `connect.ts:173`, `crud.ts:759`).
