2. Key Technical Concepts:

- **Lobu upsert identity**: `(connection_id, origin_id)`. An omitted item is never superseded, so disappearance must be emitted explicitly as a zeroed replacement row under the SAME origin id.
- **`pre-pr-remote` workflow guard is a TWO-DOT diff** (`git diff origin/main -- <files>` in `scripts/run-remote-ci.sh:76`), so it fires both when your branch changed a workflow AND when `origin/main` merely moved ahead. Same message, opposite correct responses (override vs. take the new base).
- **biome config lives at `config/biome.config.json`** — there is no root `biome.json`. Running biome bare silently reformats to tab indentation.
- **check-drift** exempts FluxCD commits (author `fluxcd@lobu.ai`, exact subject `chore: update images`); hard-fails if the pinned owletto SHA isn't an ancestor of owletto/main. Rerunning replays a stale merge ref — fix with `gh pr update-branch` or a base merge.
- **`pi-review` and `ui-review` are posted commit statuses, not auto-rerunning workflows** — any head change silently drops them, leaving the PR BLOCKED.
- **release-please regenerates its release PR on every merge to main**, dropping pi-review and the Depot attestation.
- **CLI release is two steps**: merge creates the tag; `publish-packages.yml` is `workflow_dispatch`-only, must be dispatched `--ref <tag>`, gated on green `app-image-smoke` for that exact SHA. Registry name is `@lobu/cli`.
- **Depot allows one run org-wide**; a newer dispatch cancels others.
- **A throw inside `finally` replaces the in-flight exception** — the core of the teardown-masking bug.
- **Midas readiness probe uses `markers.some(...)`** — returns on the FIRST marker, so a header-only partial render is indistinguishable from an empty portfolio.
