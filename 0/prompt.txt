2. **Key Technical Concepts:**
   - **RFC 6265 §5.4 cookie ordering**: equal-path cookies are sent **oldest-first**; server resolves the **first** occurrence. A stale host-only cookie therefore permanently outranks every newer domain-scoped one → unrecoverable login brick.
   - **Cookie scope twins**: host-only (`app.lobu.ai`) vs domain-scoped (`Domain=.lobu.ai`) cookies of the same name coexist.
   - **better-auth 1.6.8** cookie signing: `\`${token}.${makeSignature(token, secret)}\``, where `makeSignature` uses `btoa(...)` = **standard base64 (padded)**, NOT base64url. Cookie name gets `__Secure-` prefix when secure.
   - `useSecureCookies` is keyed on `NODE_ENV === "production" || https configured origin` (`auth/index.tsx:893`) — **not** on the request's forwarded proto.
   - Browsers **reject** any `Set-Cookie` for a `__Secure-`-prefixed name lacking `Secure`; and JS cannot overwrite/delete an HttpOnly cookie.
   - `__Host-` prefix would prevent duplicates structurally but forbids `Domain` — not viable given `{org}.lobu.ai` session sharing.
   - Prod infra: CNPG cluster `lobu-ai-prod-db`, ns `summaries-prod`, DB named `owletto`, `-c postgres` required; SealedSecret `summaries-app-secrets` injected via `envFrom` (so pods keep their start-time env).

     ```ts
     export const SESSION_COOKIE_BASENAME = "better-auth.session_token";

     export function hostOnlyExpiry(name: string, secure: boolean): string {
       const parts = [`${name}=`, "Path=/", "Max-Age=0", "HttpOnly", "SameSite=Lax"];
       if (secure) parts.push("Secure");
       return parts.join("; ");
     }

     export function convergeSetCookieScope(
       setCookies: string[],
       opts: { cookieDomain?: string; isHttps: boolean },
     ): string[] {
       if (!opts.cookieDomain) return setCookies;
       const out = [...setCookies];
       const expired = new Set<string>();
       for (const setCookie of setCookies) {
         const eq = setCookie.indexOf("=");
         if (eq === -1) continue;
         const name = setCookie.slice(0, eq).trim();
         if (!name || expired.has(name)) continue;
         if (!/;\s*Domain=/i.test(setCookie)) continue;
         if (isExpiry(setCookie)) continue;
         expired.add(name);
         // Mirror the source cookie's Secure, not just our own https detection
         const secure = opts.isHttps || /;\s*Secure\s*(;|$)/i.test(setCookie);
         out.push(hostOnlyExpiry(name, secure));
       }
       return out;
     }
     ```
