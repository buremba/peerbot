2. **Key Technical Concepts:**
- **Connection-pool deadlock (#2818):** `withEntityWriteTransaction` holds ONE pooled connection; a helper inside calling `getDb()` needs a SECOND while holding the first. At `DB_POOL_MAX` concurrent writers every slot is held and every writer waits for a slot only another writer can free. Session waits are unbounded → pool dead for process lifetime.
- **Diagnostic signature:** exactly `DB_POOL_MAX` sessions with `state='idle in transaction'`, `wait_event_type=Client/ClientRead`, all showing the SAME last query — the statement immediately BEFORE the offending call.
- **postgres.js `db.begin()` hands the callback a NEW `tx` object** — a Proxy around a pool handle never sees inner statements. Wrapping a real transaction makes `withEntityWriteTransaction` take its join path (`typeof db.savepoint === "function"`).
- **`TtlCache.getOrSet` stores the resolved VALUE, not the promise** — a hit costs no query, which is why the bug only bites on cold cache.
- **Session vs transaction advisory locks:** `pg_advisory_lock`/`pg_try_advisory_lock` on a reserved connection from the DEDICATED `getLockDb()` pool; `pg_advisory_xact_lock` releases at first commit. Acquire+release must be on ONE reserved connection or PG raises `you don't own a lock of type ExclusiveLock`.
- **Statement timestamps vs commit visibility:** `updated_at < syncStartedAt` orders statement times, not commit order — the ACL fence bug.
- **`ON CONFLICT … WHERE` never runs without a conflicting row** — so a timestamp fence cannot guard the INSERT path.
- **Lock ordering:** organization → children → ACL state, because org deletion holds the org row then cascades via `connections_organization_id_fkey ON DELETE CASCADE`.
- **Biome config:** the repo requires `--config-path config/biome.config.json`; running bare reformats thousands of lines.
- **Required-check verification:** diff `gh pr checks` against the branch-protection list because the `integration` fan-in is ABSENT (not pending) until it starts.

```ts
const ACL_SYNC_LOCK_NS = "acl_connection_sync";

export type AclSyncLockOutcome<T> =
	| { ran: true; value: T }
	| { ran: false; value?: undefined };

export async function withAclConnectionSyncLock<T>(
	connectionId: string,
	fn: () => Promise<T>,
): Promise<AclSyncLockOutcome<T>> {
	const reserved = await getLockDb().reserve();
	try {
		const [acquisition] = await reserved<{ acquired: boolean }[]>`
      SELECT pg_try_advisory_lock(hashtext(${ACL_SYNC_LOCK_NS}), hashtext(${connectionId}))
        AS acquired
    `;
		if (!acquisition?.acquired) return { ran: false };
		try {
			return { ran: true, value: await fn() };
		} finally {
			await reserved`
        SELECT pg_advisory_unlock(hashtext(${ACL_SYNC_LOCK_NS}), hashtext(${connectionId}))
      `;
		}
	} finally {
		reserved.release();
	}
}
```
