2. **Key Technical Concepts:**
   - MCP Apps / widgets in ChatGPT and Claude via `openai/outputTemplate` + `ui.resourceUri`; **binding is static per tool, declared at `tools/list`, so a widget cannot be conditionally suppressed** — the only way to not render one is to not declare it.
   - Versioned host-cached resource URI `ui://lobu/interaction/v12.html` (bumped v11→v12 in earlier work); ChatGPT caches successful *and* failed fetches.
   - Three coexisting presentation systems: json-template node language (charts/metrics/tables), LobuView blocks (`{title, tone, blocks[text|code|diff|form], actions}` — the only one with actions), and result-view duck-typing heuristics.
   - `@actionName` host-resolved action references (`json-template-view.tsx:53`) — a script can *name* an action but cannot inject a handler.
   - The declared-presentation envelope: `{payload_type: "json_template", payload_template: {root}, payload_data}`.
   - Result model collapsed this session from **four tiers to three**: 1=declared, 2=known shape, 3=undeclared.
   - Bun workspace, vitest + jsdom, biome (owletto CI runs `biome lint`, **not** a format check).
   - Red→green + mutation testing discipline; jsdom cannot observe painted size or CSS line-clamp, only class names and DOM position.

     **Added** `UndeclaredResult` (replaces tiers 3 and 4):
     ```tsx
     /**
      * The undeclared fallback.
      *
      * Nothing said what this result means, so the card does not pretend to know.
      * One line stating what came back, with the fields one click away. Guessing a
      * headline or promoting a "probably the answer" field is how a renderer makes
      * an arbitrary bag look intentional — and every hour spent perfecting that is
      * an hour that makes declaring a template less attractive.
      */
     const UndeclaredResult: FC<{...}> = ({ value, meta, openLink, viewState, onViewStateChange }) => {
       // A bare string or number is already its own summary — wrapping it in an
       // "N fields" line would state a field count it does not have. ValueView
       // already collapses one that runs long.
       if (value !== undefined && !isRecord(value)) {
         return <ValueView value={value} openLink={openLink} stateKey="undeclared" .../>;
       }
       const fieldCount = isRecord(value) ? Object.keys(value).length : 0;
       const summary = [fieldCount > 0 ? `${fieldCount} ${fieldCount === 1 ? "field" : "fields"}` : "No return value", meta]
         .filter(Boolean).join(" · ");
       return (
         <PersistentDetails summary={<span className="text-muted-foreground">
             <CheckCircle2 className="mr-1 inline h-3.5 w-3.5 text-green-600" />{summary}</span>}
           stateKey="details.undeclared-result.open" ... className="px-1 py-0.5 text-xs">
           <div className="mt-2 text-foreground">
             <ValueView value={value} openLink={openLink} depth={1} stateKey="undeclared" .../>
           </div>
         </PersistentDetails>
       );
     };
     ```
