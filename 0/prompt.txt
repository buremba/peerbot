## 2. Key Technical Concepts

- **Branded types as structural enforcement**: `declare const validatedBrand: unique symbol`; `ValidatedEntityRowPatch` / `ValidatedEntityRowInsert` have no public constructor, so bypassing validation is a compile error.
- **Two-tier split**: `runMutationGate` = PERMISSION ("may this principal write this field", keyed on principalKind/ownership); `validateEntityRowPatch` = VALIDATION ("is the resulting state legal", no principal/actor).
- **Deny-only verbs**: `deny(reason)`, `escalate(fields, reason)`. No `allow` — a rule can only narrow.
- **Residual vs full proposal**: the *residual* is what remains after a permission hold strips human-owned fields; the *full proposal* is what the caller asked for and what an approval card replays.
- **Scoped approval grant**: `approvedFields` (replacing the `onEscalate` mode flag) — an escalate is waived only when every field it names was on the card.
- **Batch-shaped pure isolates**: one isolate per (type, batch), not per row. Rules get no SDK (no DB/network/fs), enabling speculative dry-run.
- **Two-pass compile**: `runScript` re-esbuilds its source, so stored artifacts must be IIFE + one ESM runner.
- **`changed()` compares VALUES not key presence** — the seam passes fully MERGED metadata.
- **Mutation testing as the only reliable proof** a new test exercises its fix.
- **`pi` reviewer is NOT locked to codex** — `PI_REVIEW_PROVIDER` merely defaults to `openai-codex`; `--provider deepseek` works.

### `packages/server/src/utils/entity-management.ts` (heavily modified)
New helper (final form after two renames):
```ts
/**
 * What the rule says about the write the caller ACTUALLY proposed — `null` if it
 * is outright legal.
 *  - deny → the caller's own proposal is illegal. Deferring would mint a card no
 *    approval could clear... Returning it (rather than a boolean) lets the caller
 *    fail in the proposer's own terms; throwing the RESIDUAL's error would
 *    describe a write nobody made.
 *  - escalate → the card is right, and `fields` is what it must record. The
 *    caught residual verdict cannot supply that...
 */
async function fullProposalVerdict(params: {
	tx: DbClient; entityId: number; patch: EntityRowPatch;
}): Promise<EntityRowValidationError | null> {
	try {
		await validateEntityRowPatch({ tx: params.tx, ids: [params.entityId], patch: params.patch });
		return null;
	} catch (err) {
		if (!(err instanceof EntityRowValidationError)) throw err;
		return err;
	}
}
```

