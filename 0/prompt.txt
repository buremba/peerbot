2. **Key Technical Concepts:**
   - **Occurrence vs state edges.** Occurrences → event + two attributions (already works). State (invoice belongs to customer) → entity→entity edge.
   - **`entity_relationships` schema (baseline.sql:1204):** `id, organization_id, from_entity_id, to_entity_id, relationship_type_id, metadata jsonb, confidence real, source text, created_by, updated_by, deleted_at, created_at, updated_at`. **No valid_from/valid_to. No connection_id. No count/weight.**
   - `idx_entity_relationships_live_triple` UNIQUE on `(from,to,type) WHERE deleted_at IS NULL`.
   - `idx_entity_identities_live_unique` = `(organization_id, namespace, identifier) WHERE deleted_at IS NULL` — **excludes connection_id** (#2798).
   - **Audit-event family in `insert-event.ts`:** `insertConnectionlessAuditEvent` (awaits, throws, idempotency via `metadata._lobu_idempotency_key` = `audit:${originId}`, unique index `idx_events_org_idempotency_key`); `recordChangeEvent` (fire-and-forget, `retryWithBackoff` with `AUDIT_EVENT_RETRY = {maxRetries: 1, baseDelay: 500}`, then logs ERROR and drops). `insertEvent(params, options?: {onConflictUpdate, sql, afterPersist})` — but `insertConnectionlessAuditEvent` does NOT forward options.
   - **`semantic_type='change'` is an overloaded bucket discriminated by `metadata->>'category'`** — `'deployment'` (deployment-routes.ts:169, :236, :440), `'lifecycle'` (insert-event.ts). This is the established pattern; edge changes now use `'relationship'`.
   - **Claim set design:** `metadata.claims` keyed by `ownerId` = `${connectionId}:${ruleName}`. Bounded by owner count, never history length. Row tombstoned only when the last claim is released.
   - **`(xmax = 0)`** — the only race-safe way to know whether an `INSERT ... ON CONFLICT DO UPDATE` actually inserted.
   - **`stableJson`** (insert-event.ts:157) — key-order-independent JSON comparison; jsonb does not preserve key order.
   - **postgres.js with `fetch_types:false`** — arrays return as Postgres literals (`{10,11}`), so use `to_jsonb(col)` or `jsonb_agg` server-side. Row generic is `sql<Row>` NOT `sql<Row[]>`.
   - **`current_timestamp` is transaction start time; JS `Date` stringifies to whole seconds** — hence `to_char(updated_at, 'YYYYMMDDHH24MISSUS')` for microsecond idempotency keys.

   **`packages/server/src/utils/insert-event.ts`** (MERGED in #2807) — added `recordEdgeChangeEvent` after `recordChangeEvent`. Final (review-fix) form:
   ```ts
   interface EdgeFieldChange { field: string; old: unknown; new: unknown; }
   interface EdgeChangeEventParams {
     organizationId: string; relationshipId: number;
     fromEntityId: number; toEntityId: number;
     relationshipTypeId: number; relationshipTypeSlug: string | null;
     op: 'link' | 'unlink' | 'update_link';
     changes: EdgeFieldChange[];
     createdBy?: string | null; clientId?: string | null;
   }
   export function recordEdgeChangeEvent(params: EdgeChangeEventParams): void {
     const originId = `edge:${params.relationshipId}:${params.op}:${crypto.randomUUID()}`;
     const verb = params.op === 'link' ? 'linked' : params.op === 'unlink' ? 'unlinked' : 'updated';
     retryWithBackoff(() => insertConnectionlessAuditEvent({
       organizationId: params.organizationId,
       entityIds: [params.fromEntityId, params.toEntityId],
       originId, semanticType: 'change',
       title: `Relationship ${verb}: ${params.relationshipTypeSlug ?? params.relationshipTypeId}`,
       metadata: {
         _lobu_relationship_change: true, category: 'relationship',
         op: params.op, relationshipId: String(params.relationshipId),
         fromEntityId: String(params.fromEntityId), toEntityId: String(params.toEntityId),
         relationshipTypeId: String(params.relationshipTypeId),
         relationshipTypeSlug: params.relationshipTypeSlug, changes: params.changes,
       },
       createdBy: params.createdBy ?? null, clientId: params.clientId ?? null,
     }), AUDIT_EVENT_RETRY).catch((err) => { logger.error({...}, '[insert-event] edge change audit event DROPPED after retry — edge history is missing this row'); });
   }
   ```

   async function lockEdgeForMutation(tx: DbClient, relationshipId: number, organizationId: string): Promise<EdgeAuditRow> {
     const rows = await tx<EdgeAuditRow>`
       SELECT r.id, r.organization_id, r.from_entity_id, r.to_entity_id,
              r.relationship_type_id, r.metadata, r.confidence, r.source,
              rt.slug AS relationship_type_slug
       FROM entity_relationships r
       LEFT JOIN entity_relationship_types rt ON rt.id = r.relationship_type_id
       WHERE r.id = ${relationshipId} AND r.deleted_at IS NULL
       LIMIT 1 FOR UPDATE OF r`;
     if (rows.length === 0) throw new ToolUserError(`Relationship ${relationshipId} not found`, 404);
     if (String(rows[0].organization_id) !== organizationId) throw new ToolUserError("Access denied: relationship belongs to another organization", 403);
     return rows[0];
   }
