## 2. Key Technical Concepts

- **Depot org-wide concurrency**: only ONE CI run may exist org-wide; a newer dispatch silently cancels any in-flight run on any branch. Proven bidirectionally with different SHAs (`ee534485` vs `5c897632`).
- **The two cancel-shaped failures** (cheap discriminator): zero `failed` attempts + a workflow `error_message` ⇒ superseded by another run; exactly one `failed` + N cancelled ⇒ a real failure took the run down.
- **`.workflows[].error_message`** is the only field naming a concurrency cancellation — run-level and job-level status both omit it.
- **Attestation mechanics**: written only by the polling loop at `scripts/run-remote-ci.sh:190`; a full run `rm -f`s the marker at start; no re-attach. A killed poller ⇒ orphan run that attests nothing but still holds the slot.
- **`remote_ci_staged_tree()`** (`scripts/lib/remote-ci.sh:74`) uses `git diff --quiet --ignore-submodules=none --`, so a lagging submodule checkout reads as an unstaged change.
- **Flux deploy topology**: `flux-system` GitRepository → `https://github.com/lobu-ai/owletto.git refs/heads/main` (declared in `packages/owletto/deploy/k8s/infrastructure/flux/flux-instance.yaml`); `lobu-charts` → `lobu-ai/lobu` main. The lobu submodule pin is **not** in the deploy path.
- **curl retry semantics**: `--retry` transient set = 408, 429, 500, 502, 503, 504. `--retry-all-errors` is the documented "sledgehammer" adding non-transient errors like `(56) Connection died`.
- **bun installer contract**: `$# = 0` → `releases/latest/download/bun-$target.zip`; with a tag arg → `releases/download/$1/bun-$target.zip`.
- **Squash-merge ancestry**: squash writes a new commit with no ancestry link, so a branch reads "1 ahead" even when fully merged; verify by content diff.
- **Branch-protection required contexts on main**: `base-branch-guard, check-drift, format-lint, frontend, integration, migrations, pi-review, typecheck, ui-review, unit`.
- **`pi-review` can fail on `tests inadequate`** even with 0 bugs / 0 blockers (peer-reported).
- **The "proxy reported as the property" failure class** — the dominant recurring fault this session.
