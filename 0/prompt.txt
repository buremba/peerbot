You are helping configure IronBee deterministic verification checks for a software project.
These are project commands (type-check, lint, test, build, format-check) run at the START of a
verification cycle — before any browser/runtime verification — so the agent's changes must pass
them. Inspect the project in the current working directory (read package.json scripts, Makefile,
justfile, Taskfile.yml, pyproject.toml, Cargo.toml, go.mod/go.work, build.gradle/pom.xml, *.csproj,
mix.exs, Gemfile, composer.json, turbo.json, nx.json, pnpm-workspace.yaml, CI workflows, … as needed)
and decide which of the following check kinds this project actually supports.

Check kinds:
- typecheck: run this when the project runs a static type checker separate from its build. Examples: tsc --noEmit (TS) · mypy / pyright (Python) · flow check · sorbet tc (Ruby)
- lint: run this when the project runs a linter / static-analysis pass. Examples: eslint / biome (JS/TS) · ruff / flake8 / pylint (Python) · golangci-lint / go vet (Go) · clippy (Rust) · ktlint / detekt (Kotlin) · checkstyle / spotbugs (Java) · rubocop (Ruby) · dotnet format --verify-no-changes (.NET) · phpstan / psalm / php-cs-fixer (PHP) · credo (Elixir) · swiftlint (Swift)
- test: run this when the project has an automated test suite (run the FULL suite). Examples: vitest run / jest / npm test (JS/TS) · pytest (Python) · go test ./... (Go) · cargo test (Rust) · gradle test / mvn test (JVM) · bundle exec rspec (Ruby) · dotnet test (.NET) · phpunit (PHP) · mix test (Elixir) · swift test (Swift)
- build: run this when the project has a compile / build step worth gating. Examples: tsc -b / next build / vite build (JS/TS) · go build ./... (Go) · cargo build (Rust) · gradle build / mvn package (JVM) · dotnet build (.NET) · mix compile (Elixir) · swift build (Swift)
- format: run this when the project enforces a formatter and can run it in CHECK mode. Examples: prettier --check / biome format (JS/TS) · black --check / ruff format --check (Python) · gofmt -l (Go) · cargo fmt --check (Rust) · spotless check / ktlint (JVM) · dotnet format --verify-no-changes (.NET) · mix format --check-formatted (Elixir)

Rules:

Respond with ONLY a JSON object, no prose, no markdown, in EXACTLY this shape:
