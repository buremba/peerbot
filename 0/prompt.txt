2. **Key Technical Concepts:**
   - MCP Apps/widgets bind **statically per tool** via `mcpMeta` (`openai/outputTemplate` + `ui.resourceUri`), declared at `tools/list`. A tool without `mcpMeta` can never reach the widget renderer.
   - Versioned host-cached resource URI `ui://lobu/interaction/vN.html`; ChatGPT caches both successful and failed fetches. Old versions must stay in `MCP_APP_RESOURCE_ALIASES`.
   - Three-tier result model: 1 = declared (json_template/LobuView), 2 = known shape, 3 = undeclared. No fourth tier by design.
   - `SdkScriptResultSchema` **under-declares** 5 fields the handler actually returns (`logs`, `duration_ms`, `sdk_calls`, `sdk_call_trace`, `sdk_call_trace_truncated`) — a known, unfixed server bug.
   - Owletto is a git submodule; it has **no biome config** and uses biome's tab defaults. The parent config (`config/biome.config.json`) is space-indented and excludes `.claude/worktrees/**`.
   - Owletto merge order (from memory): parent green **including ui-approve** → merge owletto PR → repin → merge parent. Merging owletto first reddens `check-drift` on every open PR.
