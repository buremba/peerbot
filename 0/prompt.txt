2. **Key Technical Concepts:**
- **Commit-visibility race:** `updated_at < syncStartedAt` orders **statement** timestamps, not commit visibility. An invalidation stamping at T1 and committing at T3 is invisible to a sync starting at T2 (T1<T2<T3), yet the fence reads T1<T2 and blesses `fresh`.
- **Org-scoped generation counter:** `organization.acl_generation bigint NOT NULL DEFAULT 0`, read before membership, compared under `FOR SHARE` at stamp time. Must be **org-scoped, not per-row**, because `ON CONFLICT … WHERE` never runs without a conflicting row — so a per-row counter cannot fence the INSERT path.
- **`IS NOT DISTINCT FROM` vs `=`:** synthetic orgs with no `organization` row must compare NULL to NULL, or the materializer silently stops stamping for every standalone graph test.
- **`pgrep -f "make pre-pr-remote"` matches its own command line** → phantom peer gates; self-matching wait loops.
- **`| tail -N` buffers to EOF** → killed pipelines write zero bytes; the pipe masks make's exit status (a FAILED gate reported as "exit code 0").
- **A killed local gate leaves a live Depot run** which cancels peer jobs org-wide, surfacing as `server-integration-bun: cancelled`.
- **Two GitHub API surfaces:** `pi-review`/`ui-review` appear ONLY in the commit **status** API; the other 8 required contexts appear ONLY in **check-runs**.
- **vitest vs bun:test:** server integration tests importing from `vitest` run under `server-integration-vitest`; `bun test` is the wrong runner and yields spurious failures.
- **dbmate migration convention:** `-- migrate:up` / `-- migrate:down` markers required.

```ts
/** Fail closed every ACL projection whose entity graph changed outside a sync. */
export async function invalidateOrgAcl(tx: DbClient, orgId: string): Promise<void> {
  // Lock the generation before ACL-state rows. `markAclFresh` uses the same
  // order, so its comparison cannot read an old generation and then wait behind
  // the invalidation's state-row lock.
  await bumpAclGeneration(tx, orgId);
  await tx`
    UPDATE authz_source_acl_state
    SET freshness_state = 'stale', updated_at = clock_timestamp()
    WHERE organization_id = ${orgId}
  `;
}
```
