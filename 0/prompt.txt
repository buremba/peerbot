   - **`packages/owletto/src/components/agents/behaviors/behavior-trigger-editor.tsx`** — THE fix. Added `declaredMatch()` after `preserveResourceMatch`:
     ```ts
     /**
      * `match` applies to every subscribed event, so the emitted filter may only
      * carry fields the current selection actually advertises — otherwise adding a
      * second event silently gates it on a field that event never populates.
      *
      * Narrowing happens here, at serialization, rather than by clearing the form
      * state: toggling an event off and back on is a navigation step, not an intent
      * to discard the value the author typed. `resource_ref`/`resource_type` are the
      * resource-prefill contract rather than connector filter fields, so they are
      * carried regardless of what the event's schema declares.
      */
     function declaredMatch(
         filter: Record<string, unknown>,
         schema: { properties?: unknown } | undefined,
     ): Record<string, unknown> {
         const declared = new Set(
             Object.keys((schema?.properties as Record<string, unknown>) ?? {}),
         );
         return Object.fromEntries(
             Object.entries(filter).filter(
                 ([key]) =>
                     key === "resource_ref" || key === "resource_type" || declared.has(key),
             ),
         );
     }
     ```
