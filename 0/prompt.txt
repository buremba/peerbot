2. **Key Technical Concepts:**
   - **Drift gate for `lobu apply`**: fail-closed on un-declared remote state (UI field edits, UI-created definitions) instead of overwriting/auto-deleting under `prune`.
   - **Three-way attribution**: `desired` (config) / `remote` (cloud) / `attribution` (effective remote after last succeeded apply). Converge only when `remote == attribution`; block when `remote ≠ attribution AND desired ≠ remote`.
   - **`owned` set**: kind-qualified incarnation identities (`entity-type:12`, `watcher:b-1`, `connector-definition:5`) that determine delete eligibility. UI-created (unowned) definitions never auto-delete.
   - **Prune-aware facets**: `required`, `properties`, `eventKinds`, `viewTemplate`, `resolutionPolicy` — declared → diff; omitted + prune → removal; omitted + no prune → unmanaged.
   - **Baseline storage**: `{attribution, owned}` inside the deployment event's `payload_data.manifest`, read back via new `GET /api/<org>/deployments/latest`.
   - **Partial index**: `events_succeeded_deployments_idx` on `(organization_id, id DESC) WHERE semantic_type='change' AND metadata->>'category'='deployment' AND metadata->>'status'='succeeded'`, built `CONCURRENTLY` with an INVALID-carcass heal.
   - **`pi-review` gate thresholds** (`docs/REVIEW_SCHEMA.md`): passes only when `bug_free>=80`, `slop<=15`, `simplicity>=70`, `bugs==0`, `blockers==[]`, `tests_adequate==true`. Per-run override: `PI_REVIEW_MIN_SIMPLICITY=<n>`.
   - **`make pre-pr-remote`**: runs 16–18 Linux CI lanes on Depot against the *staged* tree, records a tree-hash attestation that `make review` requires.
   - **Stale dist trap**: `packages/cli/bin/lobu.js` dynamically imports `../dist/index.js` — source edits are invisible to E2E until `bun run build`.
