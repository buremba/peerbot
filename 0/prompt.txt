## 2. Key Technical Concepts

- **Open set vs closed set enumeration** — the core design insight. Enumerating "everything a dry run must not do" grows forever; enumerating "what it must keep" (preview + run row lifecycle) is closed and lets a transaction cover the rest.
- **Transaction-rollback dry run** — dry path runs identical ingest code against a tx that always rolls back via a `DRY_RUN_ROLLBACK` Symbol sentinel; postgres.js rolls back when the `begin` callback throws.
- **"Escapes the tx" guard category** — only non-Postgres effects need explicit guards: ArtifactStore blob upload, Behavior run dispatch, detached auto-linking, transcription.
- **`insertEvent` advisory-lock contract** — `insert-event.ts:481`: `if (options?.onConflictUpdate && !options.sql && ...)`. Supplying `sql` at all SKIPS the advisory-lock dedup that serializes concurrent ingests of the same `(connection_id, origin_id)`.
- **Credential invariant** (`packages/server/AGENTS.md:28-31`) — workers never receive real credentials; only device-pinned connectors and short-lived provider-derived leases. This is why `lobu connector run` only supports `browser_session`.
- **Sequence non-transactionality** — `events.id` defaults to `nextval('public.content_id_seq')`; rolled-back nextval values are permanently consumed, so a dry run leaves id gaps (harmless, but "persists nothing" is imprecise — no rows persist, the counter moves).
- **release-please flow** — release-please PR bumps files + creates `lobu-vX.Y.Z` tag/release, which auto-dispatches `publish-packages.yml` with `bump=skip`. `publish-packages.yml` has `contents: read` and never commits, so a manual `bump=<level>` publishes to npm and silently desyncs the repo.
- **Squash merges break ancestry** — rollout gates must use the squash commit, merge commit first in `git merge-base --is-ancestor`.
- **Subprocess error channel** — `CONNECTOR_RUNNER_CODE` runs in a subprocess reporting via `process.send({ success: false, error: error.message })`; a string is the only channel, so typed errors aren't available.
- **bwrap / uid_map** — `charts/lobu/values.yaml:84-125` records that bubblewrap cannot be enabled on the managed cluster because uid_map is runtime-restricted; contributed CLIs exiting 127 is intended and documented ("Do not re-open this as a bug").

```ts
const ingestBatch = async (db: DbClient) => {
  // ESCAPES THE TX: uploads a blob to ArtifactStore
  if (!isDry) {
    const { items: materializedItems, pendingTranscriptions: pending } =
      await materializeInlineAttachments(batch.items);
    batch.items = materializedItems as typeof batch.items;
    pendingTranscriptions = pending;
  }
  // Runs on dry too, against `db` — rolls back with everything else
  await applyEventAttributions({...}, db);
  ...
  const inserted = await insertEvent({...}, {
    onConflictUpdate: true,
    // Dry path only. The real path must NOT pass `db` even though it equals
    // the singleton: a caller-supplied `sql` makes insertEvent skip its
    // advisory-lock dedup transaction.
    sql: isDry ? db : undefined,
    afterPersist: async (persisted, tx) => {...},
  });
  // ESCAPES THE TX: dispatches real Behavior runs
  if (!isDry) { await dispatchBehaviorRunsBestEffort(activations); }
  if (inserted) {
    totalItems++;
    // ESCAPES THE TX: detached, writes through getDb() singleton
    if (entityIds.length > 0 && !isDry) { autoLinkEvent({...}).catch(() => {}); }
    if (isDry && dryPreview.length < DRY_RUN_PREVIEW_LIMIT) { dryPreview.push({...}); }
  }
  ...
  if (!isDry) { triggerAudioTranscriptions(run.organization_id, pendingTranscriptions); }
  // No dry guard: checkpoint writes go to the tx and vanish with it
  if (batch.checkpoint) { await db`UPDATE feeds SET checkpoint = ...`; await db`UPDATE runs SET checkpoint = ...`; }
  return { totalItems, rejectedItems };
};

const DRY_RUN_ROLLBACK = Symbol("dry-run-rollback");
let outcome: Awaited<ReturnType<typeof ingestBatch>> | null = null;
if (isDry) {
  try {
    await sql.begin(async (tx) => {
      outcome = await ingestBatch(tx);
      throw DRY_RUN_ROLLBACK;
    });
  } catch (err) {
    if (err !== DRY_RUN_ROLLBACK) throw err;
  }
} else {
  outcome = await ingestBatch(sql);
}
if (outcome === null) {
  throw new Error("[stream] batch completed without an outcome");
}
```
