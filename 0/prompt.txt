## 2. Key Technical Concepts

- **Gate sequence**: `make review-fix` → stage by explicit path → `make pre-pr-remote` (Depot, 16–18 lanes, tree attestation) → commit → push → `gh pr create` → `make review` (posts required `pi-review`) → `make ui-review` → `gh pr merge --squash --admin`.
- **Depot concurrency (ROOT CAUSE FOUND)**: `.github/workflows/ci.yml:25` declares `group: ci-${{ github.ref }}` + `cancel-in-progress: true`; `scripts/run-remote-ci.sh:115` invokes `depot ci run --workflow ... --org ...` with **no ref**, so `github.ref` is empty and every dispatch collapses into a group literally named `ci-`. Newest dispatch cancels any in-flight run org-wide. **This is our file, not a Depot-side policy.**
- **Cancel-shaped failure discriminator**: zero `failed` attempts + workflow `error_message` = superseded (rerun, diff fine); exactly one `failed` + N cancelled = real failure (read THAT attempt's log).
- **Review commit lock** (`scripts/lib/review-commit-lock.sh`): FD 9 inherited by children so kernel flock survives parent death; PID in the lock file is diagnostic only.
- **Verdict recovery**: a dead review usually already wrote its verdict — `tr -d '\000' < /tmp/lobu-review-codex-inline.<id>.stderr | grep -o '{"bug_free_confidence".*}' | tail -1`.
- **`make review` does NOT dispatch Depot** — it requires and reuses an existing attestation.
- **Flux reads owletto repo directly** (`refs/heads/main`), not the submodule pin — pointer bumps are not deploys.
- **Depot attestation is vacuous for submodule-pointer PRs** — gitlink lives in the index; `git apply` without `--index` drops it.
- **curl retry semantics**: `--retry` covers HTTP 408, 429, 500, 502, 503, 504; `--retry-all-errors` is the documented "sledgehammer" needed only for non-HTTP errors like `(56) Connection died`.
- **bun**: ignores `timeout` in bunfig (CLI `--timeout` only); default test timeout 5000ms; 15 `bun-version: 1.3.5` pins repo-wide, all Dockerfiles install unpinned `latest`.
- **Exit-code laundering**: the harness reports the status of the *last* thing the command line runs — a pipe, `;`, or trailing `echo` all discard it. Correct shape: `make X > log 2>&1; RC=$?; echo "MAKE_EXIT=$RC" >> log; exit $RC`.
