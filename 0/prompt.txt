## 2. Key Technical Concepts

- **MCP (Model Context Protocol)** — Streamable HTTP transport, `Mcp-Session-Id`, `clientInfo` at initialize, `tools/list`, `isError` on tool results, `outputSchema`
- **Single-source tool registry** — `tools/registry.ts` → TypeBox schemas → `openapi-generator.ts` → OpenAPI spec → `@hey-api/openapi-ts` → `packages/client/src/generated/sdk.gen.ts`. Confirmed no drift possible by construction.
- **ClientSDK** — 18 flat namespaces in `packages/server/src/sandbox/namespaces/` (agents, behaviors, entities, knowledge, conversations, connections, feeds, classifiers, schedules, metrics, notifications, operations, organizations, catalog, auth-profiles, entity-schema, view-templates, action-call), reachable via `run_sdk`/`query_sdk`
- **Conversation identity layering** — `oauth_clients` (OAuth registration, months) / `mcp_sessions` (1hr idle TTL) / `conversations` (navigable unit)
- **String-encoded identity anti-pattern** — routable id, platform, and origin all packed into `conversation_id`, re-parsed by multiple readers
- **Behaviors** — headless scheduled agent runs (`HEADLESS_SOURCES`), the mechanism `generate-starters.ts` duplicates
