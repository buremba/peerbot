   - **Permission vs Validation split**: `runMutationGate` answers "may this principal write this field" (keyed on `principalKind`/ownership/approval); validation answers "is the resulting state legal" (principal-free)
   - **Validate-then-transform bug** (found by codex): gate validates a proposal, then approval-stripping and ownership-merge rewrite it, then the transformed patch commits
   - **Branded type enforcement**: `ValidatedEntityRowPatch` with `declare const validatedBrand: unique symbol` — skipping validation becomes a compile error
   - **"The funnel funnels SQL, not policy"**: `check-entity-write-funnel.mjs` proves no entity SQL outside `entity-management.ts`, but that file has 3 writers
   - **Approval laundering hole**: `entity-field-approval.ts` writes via 4 paths, called `runMutationGate` zero times
   - **Measured isolate cost**: 4.53ms p50 / 5.32ms p95 / 7.18ms max; declarative 0.08µs (~54,000×)
