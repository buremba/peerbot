## Useful facts
- ACL row: table `authz_source_acl_state`, keyed (organization_id, connection_id).
  Columns: acl_support ('none'|'partial'|'full'), freshness_state
  ('fresh'|'stale'|'failed'), last_synced_at, updated_at.
- Enforcement needs acl_support='full' AND freshness_state='fresh' AND synced
  within ACL_STALE_AFTER_MINUTES=60. Any non-enforcing row fails CLOSED.
- Runtime connection ids look like `agentconn-<slug>`; `connections.slug` is the
  join key (strip the prefix).
- The webhook route is packages/server/src/routes/public/app-webhooks.ts (edge
  signature check at ~line 1066) then the Slack coordinator takes over.
- Live Slack connections + their bound channels: see
  `resolveBoundChannelRows` and table `channel_messages` / behavior subscriptions.
