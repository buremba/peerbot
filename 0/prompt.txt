2. Key Technical Concepts:

- **Depot org-wide concurrency collapse**: `ci.yml` declared `group: ci-${{ github.ref }}`; `depot ci run` passes no ref → group becomes literal `ci-` → newest dispatch cancels all others org-wide. Fixed with `|| github.run_id` fallback.
- **The two cancel-shaped failures (discriminator)**: zero `failed` attempts + a workflow `error_message` ⇒ superseded; exactly one `failed` + N cancelled ⇒ a real failure took the run down.
- **`gh run rerun` replays the stale merge ref** — a check-drift failure from a missing bump can never clear by rerunning; the branch must take the new base (`gh pr update-branch`).
- **Gitlink-only merge preserves the attestation**: if the merged tree hash equals the attested one, no re-gate is needed (`git rev-parse HEAD^{tree}`).
- **Depot attestation is vacuous for pointer PRs**: injector uses `git apply --allow-empty` with no `--index`; gitlink lives in the index so the patch is dropped; `.depot/actions/setup-submodule/action.yml` then checks out the BASE pin.
- **check-drift exempts FluxCD commits** only when author `fluxcd@lobu.ai` AND exact subject `chore: update images` AND touches only `deploy/`. It also hard-fails if the pinned SHA isn't an ancestor of owletto/main.
- **Flux deploy topology**: reconciles from `lobu-ai/owletto.git refs/heads/main` directly — the lobu submodule pin is NOT in the deploy path.
- **release-please regenerates its PR on every merge to main**, dropping `pi-review` and the Depot attestation.
- **CLI release is two steps**: merge creates the tag; `publish-packages.yml` is `workflow_dispatch`-only, must be dispatched `--ref <tag>`, gated on green `app-image-smoke` for that exact SHA. Registry name is `@lobu/cli`, not `lobu`.
- **bun ignores `timeout` in bunfig** — only the CLI `--timeout` applies. Embedded-Postgres cold start (initdb) exceeds the 5000ms default on a fresh worktree's first run.
- **Lobu upsert identity**: `(connection_id, origin_id)` — an omitted item is never superseded, so disappearance must be emitted explicitly.

```yaml
# The `github.run_id` fallback exists for `depot ci run`, which `make
# pre-pr-remote` uses to execute this same file against a local staged tree.
# That path supplies no ref, so `github.ref` expanded empty and every local
# dispatch in the org collapsed into one group literally named `ci-`. Combined
# with cancel-in-progress, the newest gate anywhere killed whatever was running
# — a different branch, a different worktree, a different person — and the
# victim saw only "Cancelled due to the workflow concurrency policy", which
# names this block rather than any Depot-side limit. Two dispatchers that each
# retry on cancellation then deadlock, neither ever attesting. Falling back to
# the run id gives each local dispatch its own group. GitHub keeps the per-ref
# behaviour unchanged: `github.ref` is always set for push and pull_request.
concurrency:
  group: ci-${{ github.ref || github.run_id }}
  cancel-in-progress: true
```
