2. **Key Technical Concepts:**
- **The ACL hole:** `member_of` is both an ACL primitive the authz gates read AND ordinary domain vocabulary any caller can create. `ensureMemberOfType` upserts on `(organization_id, slug)` so it ADOPTS pre-existing org-authored rows.
- **`source` cannot carry the boundary:** ACL syncs write `source: 'feed'`, which is also in `CALLER_SETTABLE_SOURCES = ['ui','llm','feed','api']`, so caller-minted edges are byte-identical to sync-minted ones.
- **Transaction-local GUC chokepoint:** `SET LOCAL lobu.acl_write = 'on'` via `set_config(..., true)`, enforced by a `BEFORE INSERT OR UPDATE OR DELETE` row trigger on `entity_relationships`.
- **Rollout split (A1/A2):** classification (not the trigger) is what breaks a rolling deploy. A1 ships everything inert; A2 classifies.
- **D8=C:** merge/unmerge/force-delete DROP authorization edges rather than repointing/restoring; next sync re-derives.
- **postgres.js semantics:** transaction objects expose `savepoint`, not `begin`; `result.count` gives affected rows; `clock_timestamp()` vs `current_timestamp` (transaction-start) matters for fences.
- **NULL-safety in SQL predicates:** `NOT (NULL = 'x' OR ...)` evaluates to NULL, silently excluding rows; requires `IS NOT DISTINCT FROM`.
- **Depot serializes org-wide;** a newer dispatch cancels a peer's running gate.
- **Generated-client drift guard:** `typecheck` fails if `packages/core/src/contracts/tools/**` or `packages/server/src/gateway/routes/**` change without regenerating `packages/client/src/generated/**`; `[client-regen-not-needed]` sentinel in a commit message skips it.
- **`lobu apply` prune semantics:** an unowned undeclared remote type becomes **blocking drift** (aborts apply), NOT a delete.

**`packages/server/src/utils/relationship-validation.ts`** — final consolidated form:
```ts
export type RelationshipTypePurpose = 'authorization';
export const PURPOSE_AUTHORIZATION: RelationshipTypePurpose = 'authorization';
const ACL_MANAGED_SLUG = 'member_of';
export function isAclManagedRelationshipSlug(slug: string): boolean {
  return slug === ACL_MANAGED_SLUG;
}
export const ACL_MANAGED_TYPE_SQL =
  `(rt.purpose IS NOT DISTINCT FROM '${PURPOSE_AUTHORIZATION}'` +
  ` OR rt.slug IS NOT DISTINCT FROM '${ACL_MANAGED_SLUG}')`;

export async function withAclEdgeWrite<T>(db: DbClient, fn: (tx: DbClient) => Promise<T>): Promise<T> {
  return db.begin((tx: DbClient) => withAclPrivilege(tx, () => fn(tx))) as Promise<T>;
}
export async function withAclPrivilege<T>(tx: DbClient, fn: () => Promise<T>): Promise<T> {
  await tx`SELECT set_config('lobu.acl_write', 'on', true)`;
  try { return await fn(); }
  finally { await tx`SELECT set_config('lobu.acl_write', 'off', true)`.catch(() => {}); }
}
export function assertNotAuthorizationType(type, action): void { refuseAclManaged(type, action, false); }
export function assertNotAclManagedEdge(type, action): void { refuseAclManaged(type, action, true); }
function refuseAclManaged(type, action, includeSlug): void {
  const managed = type.purpose === PURPOSE_AUTHORIZATION ||
    (includeSlug && isAclManagedRelationshipSlug(type.slug ?? ''));
  if (!managed) return;
  throw new ToolUserError(`Relationship type '${type.slug ?? 'unknown'}' is authorization-bearing and cannot be modified via ${action}. Access-granting edges are maintained by the connector ACL syncs.`, 403);
}
```
