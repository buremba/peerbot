BACKGROUND
Connectors sync external data. A connector's sync() returns SyncResult (packages/connector-sdk/src/connector-types.ts:870) which carries ONLY events. Events are turned into entities by declarative 'attributions' rules on an eventKind (same file, ~line 540-625: EventAttributionRule, EventAttributionTargetSpec, EntityIdentitySpec with namespace/eventPath/primary, autoCreate, traits). The engine that executes these is packages/server/src/utils/entity-link-upsert.ts.

THE GAP: attributions link EVENT -> ENTITY. There is no way for a connector to declare ENTITY -> ENTITY edges (rows in the entity_relationships table). The word 'relationship' does not appear in connector-types.ts at all.

RELEVANT HISTORY: commit 88dab5bf2 'refactor(server): delete the identity-fact engine (#2416)' deleted a prior mechanism that derived relationship edges from compiled 'autoCreateWhen' rules stored on entity_relationship_types.metadata. Read that commit message. It was deleted as a 'parallel, unused identity mechanism'.
