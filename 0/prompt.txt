## 2. Key Technical Concepts

- **Slack ACL gate:** `authz_source_acl_state` per (org, connection). Enforcement requires `acl_support='full'` AND `freshness_state='fresh'` AND synced within `ACL_STALE_AFTER_MINUTES = 60`. Any non-enforcing row **fails closed**. States: `enforced`, `stale`, `not-graphed`.
- **Connection-wide stamp vs per-scope build:** the ACL state row is keyed `(organization_id, connection_id)`, but `buildAccessGraph` runs per resource-set. Slack Grid = one connection, many workspaces → stamping inside the loop reopens the gate while later workspaces hold pre-revocation edges.
- **`current_timestamp` = transaction start; `clock_timestamp()` = statement time.** Mixing them across a fence and its writer creates a race.
- **Edge reconciliation is per-resource** (`to_entity_id = resourceEntityId`), so a per-team `buildAccessGraph` loop is safe for edges — only the stamp is connection-wide.
- **Webhook verification order:** `routes/public/app-webhooks.ts:1066` runs `provider.verify(...)` → 401 BEFORE the Slack takeover delegates to the coordinator.
- **Slack manifest API deadlock:** `apps.manifest.update` replaces wholesale and validates first. For app `A096D2P623B`: with `external_auth_providers` → `team_not_eligible: OauthProviders cannot be created on a free team`; without → `unable_to_delete_providers: mcp_dcr_lobu`. **No payload validates.**
- **Lobu browser bridge:** `lobu call run_sdk --org buremba` → `client.operations.execute({ connection_id: 479, operation_key, input })`. Ops: navigate, evaluate, click_ref, type_ref, focus_tab, release_tab, close_tab, get_accessibility_tree, wait_for_selector, console_capture_{start,drain,stop}, network_intercept_*, screenshot, upload_file, close_user_tabs, show_notification.
- **`click_ref` schema:** `ref: { document_epoch: int, ref_id: int }` — NOT `ref_id` at top level, NOT a bare int.
- **Background tabs don't paint virtualized lists** — the Slack event picker sized to 58px but rendered nothing until `focus_tab`.
- **`query_sdk` is read-only and rejects `connections.test`; `run_sdk` allows it.** Scripts need `export default async function () { … }`.
- **`authProfiles.get` takes `auth_profile_slug`, not an id.** `profile_kind`: `oauth_app` (app-level creds) vs `oauth_account` (per-user grant).
- **vitest EXCLUDES `packages/server/src/gateway/**/__tests__`** — those run under `bun test ./<path>`.
- **opencode auto-rejects writes outside cwd** (`external_directory (/tmp/*)`) and exits 0 — the known trap.
- **`gh pr checks` omits unreported required contexts**; `pi-review` and `ui-review` report via the *status* API, not check-runs. Must diff against the branch-protection list.

```ts
export function aclConnectionIdSql(tableAlias?: "c"): string {
  const prefix = tableAlias ? `${tableAlias}.` : "";
  return `CASE
    WHEN ${prefix}credential_mode IS NULL THEN ${prefix}id::text
    WHEN left(${prefix}slug, length('agentconn-')) = 'agentconn-'
      THEN substr(${prefix}slug, length('agentconn-') + 1)
    ELSE ${prefix}slug
  END`;
}

export async function deleteConnectionAclRow(sql, params): Promise<void> {
  await sql`
    DELETE FROM authz_source_acl_state a
    USING connections c
    WHERE c.id = ${params.connectionId}
      AND c.organization_id = ${params.organizationId}
      AND a.organization_id = c.organization_id
      AND a.connection_id = ${sql.unsafe(aclConnectionIdSql("c"))}
  `;
}
```
