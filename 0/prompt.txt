2. **Key Technical Concepts:**
   - **ESM vs CJS globals**: `__filename`/`__dirname` are ambient in CJS and in **bun's** ESM, but undefined in **node's** ESM
   - **Dual-output packaging**: `@lobu/worker` emits both CJS `dist/index.js` (tsc, declared package entry) and ESM `dist/index.bundle.mjs` (esbuild, what the gateway actually spawns)
   - **Extension-based runtime selection**: `buildWorkerInvocation` spawns `.ts` under bun, `.mjs`/`.js`/`.cjs` under node
   - **esbuild `define` as scope-aware detector**: `define` substitutes only *unbound* identifier references, leaving locally-declared bindings alone — used as a probe pass for unbound CJS globals
   - **glibc symbol versioning**: `__isoc23_strtol@GLIBC_2.38` is the gcc-13 accidental uplift; a shared library's build-host glibc becomes the product's support floor
   - **embedded-postgres `createPostgresUser`**: must be conditional — `getUidAndGid()` returns `{}` when non-root, making the flag trigger `groupadd`/`useradd` for everyone
   - **Keyless e2e**: `LOBU_PROVIDER_REGISTRY_PATH` + `scripts/sdk-e2e/mock-openai.mjs` gives a deterministic provider needing no secrets
   - **Egress bootstrap gating**: `createEmbeddedBashOps` runs unconditionally per turn, but `buildEgressFetch` only when `allowedDomains.length > 0`
   - **CLI public vs internal config keys**: public `NetworkConfig` is `{ allowed, denied }`; internal core is `{ allowedDomains, deniedDomains }` — mismatched keys are silently dropped
   - GitHub Actions job-level `container:`, matrix-conditional containers, `workflow_run` triggers
