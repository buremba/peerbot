2. **Key Technical Concepts:**
   - **macOS TCC**: grants keyed to bundle identifier + code signing requirement (csreq), NOT path. `kTCCServiceScreenCapture`, `kTCCServiceAccessibility`, `kTCCServicePostEvent`, `kTCCServiceSystemPolicyAppData`. System db at `/Library/Application Support/com.apple.TCC/TCC.db` (root-only), user db FDA-protected.
   - **Designated requirement**: `identifier "com.owletto.mac" and anchor apple generic and certificate leaf[subject.CN] = "Apple Development: Burak Emre Kabakci (8NVN2W85G3)"` — identity-based, no path component, so a build at any path with the same cert inherits grants.
   - **`log` shell-function shadowing**: a zsh function named `log` intercepts `/usr/bin/log`, failing with "too many arguments"; with stderr suppressed this looks like empty output.
   - **os.Logger `privacy: .public`**: default is `.private`, rendering values as `<private>`.
   - **`LSUIElement`** apps launched by LaunchServices discard stdout, so `print()`/NSLog-to-stdout is invisible.
   - **`@MainActor` blocking I/O**: `AppState` is `@MainActor`; a blocking `open()` there parks the menu bar, poll loop, and heartbeat.
   - **AppleScript UI scripting** on menu bar apps: `click menu bar item 1 of menu bar 2` works because System Events has its own Accessibility grant; NSPopover closes on focus loss so click + capture must be one shell command.
   - **Xcode project registration**: single target, no `PBXFileSystemSynchronizedRootGroup`, so new files need 4 pbxproj entries (PBXBuildFile, PBXFileReference, group child, Sources phase).
   - **`apps/mac/Tests/run-tests.sh`**: standalone `@main` executables; the `swiftc` invocation is extracted from each file's header comment and executed verbatim.
   - **Poll intervals**: `actionPollInterval = 10` when computer use active, else `feedPollInterval = 600`; online threshold 20 minutes.
   - **Device-worker pinning**: connections pinned to a `device_worker_id`; relaunching the app registers a new worker identity and strands them.
   - Submodule merge order (owletto PR first, then pointer bump to the **squash** SHA); squash merges break ancestry checks.
